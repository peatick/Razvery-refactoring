# tic_map_editor

SDL2 + C++20 で作った、TIC-80のマップエディタ風ツールです。
`img.png` を 8x8px 単位のタイルセットとして読み込み、左のパレットから
タイルを選んで右側のマップに配置していきます。各タイルには8個の
ON/OFFフラグ(TIC-80のスプライトフラグ相当)を設定できます。

マップのサイズには上限を設けていません(チャンク方式、詳細は下記)。
上下左右どこまでもパンして、どこにでもタイルを置けます。

## ファイル構成

- `canvas.hpp`       : テクスチャの拡大縮小・パン、グリッド/セルのヒットテストを
                        提供する基底キャンバスクラス
- `tileset.hpp`       : img.png を8x8pxに分割し、タイルごとに8bitフラグを保持するクラス
- `palette_canvas.hpp`: タイルセットを表示し、タイル選択・フラグ設定を行うキャンバス
- `map_canvas.hpp`    : 選択中のタイルをマップに配置していくキャンバス(チャンク方式・無制限)
- `main.cpp`          : ウィンドウ生成・メインループ
- `img.png`           : 動作確認用のサンプルタイルセット(64x64px = 8x8タイル)

## タイルのインデックスとフラグの対応

`tileset.hpp` の規則:

```
index = row * columns + col
(col=0,row=0) -> index 0  = フラグ配列 flags[0] の bit0〜bit7
(col=1,row=0) -> index 1  = flags[1] の bit0〜bit7
(col=0,row=1) -> index = columns
```

つまり「タイル1枚ごとに8個のフラグ(bit0〜7)」を持つ形です。
パレット上でタイルにマウスを乗せて `0`〜`7` キーを押すと、そのタイルの
該当フラグがトグルされます。ONのフラグはタイル左上に色付きドットで表示されます
(ズームインすると見やすくなります)。

フラグは `img.png.flags` というテキストファイルに自動保存/読込されます
(1行目がタイル0、2行目がタイル1…という8bit値の10進数)。

## マップサイズについて(無制限/チャンク方式)

SDLのテクスチャには最大サイズの制限があるため、マップ全体を1枚のテクスチャに
することはできません。そこで `MapCanvas` はマップを **chunkSize x chunkSize
タイル(既定16x16)の「チャンク」** に分割し、実際にタイルが置かれたチャンクだけを
`std::unordered_map` で動的に生成します。各チャンクは 128x128px 程度の
render-targetテクスチャを1枚持ち、タイルを置く/消すたびにその中の該当8x8pxだけを
焼き直します。描画時は画面に映っている範囲のチャンクだけを1個ずつ貼り付けるので、
マップがどれだけ広がってもメモリ・描画コストは「実際に使われたチャンク数」にしか
比例しません。座標も `int` の範囲内(概ね±21億)であれば負の値も含め自由に使えます。

保存ファイル(`map.dat`)も「置かれているタイルの一覧」だけを記録する疎な形式なので、
広い範囲にまばらにタイルを置いても無駄に大きくなりません。

チャンクサイズは起動引数で変更できます(後述)。小さくすると細かい単位で
メモリ管理される代わりにチャンクの数が増え、大きくすると逆になります。
基本的には既定値(16)のままで問題ありません。

## ビルド

```bash
sudo apt install libsdl2-dev libsdl2-image-dev g++
g++ -std=c++20 -O2 -Wall -Wextra $(sdl2-config --cflags) main.cpp \
    -o tic_map_editor $(sdl2-config --libs) -lSDL2_image
```

## 実行

```bash
./tic_map_editor [画像パス] [チャンクサイズ(タイル数、既定16)]
# 例: ./tic_map_editor img.png
# 例: ./tic_map_editor img.png 32
```

## 操作方法

**左パネル(タイルパレット)**
| 操作 | 内容 |
|---|---|
| 左クリック | 描画に使うタイルを選択 |
| ホバー中に `0`〜`7` | そのタイルのフラグ(bit)をON/OFF切替 |
| ホイール | ズーム |
| 中ドラッグ | パン |

**右パネル(マップ)**
| 操作 | 内容 |
|---|---|
| 左クリック / 左ドラッグ | 選択中のタイルを配置 |
| 右クリック / 右ドラッグ | タイルを消去 |
| ホイール | ズーム |
| 中ドラッグ | パン |

**全体**
| 操作 | 内容 |
|---|---|
| `Ctrl+S` | マップを `map.dat` に、フラグを `img.png.flags` に保存 |
| `Ctrl+L` | `map.dat` からマップを再読み込み |
| `Esc` | 終了(終了時も自動保存されます) |

## 拡張のヒント

- フラグの意味(「歩行不可」「水」など)をUIに表示したい場合は、SDL_ttf を
  追加して `PaletteCanvas::onOverlayRender` にテキスト描画を足すのが簡単です。
- タイルセット画像を差し替えたい場合、`Tileset` を作り直して
  `PaletteCanvas`/`MapCanvas` に渡し直してください(現状はコンストラクタで
  タイルセットの参照を固定しています)。
